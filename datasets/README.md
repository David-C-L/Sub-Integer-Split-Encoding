# Input datasets

All measurements use the 524,288-row prefix of each column (Section 2 study, Section 7 throughput) or the full
column (Section 7 sizes). `columns_524k/` ships the 524,288-row prefix of every column whose licence allows
redistribution, as xz-compressed text (`<name>.txt.xz`) with one value per line, in file order.
`scripts/unpack_data.sh --columns` decompresses them to `columns_524k/<name>.txt` (about 150 MB); the
figure and table scripts do not need them. Every other column must be rebuilt from its
source with the scripts in `scripts/` and then cut with `make_columns_524k.py`.

```
python3 datasets/make_columns_524k.py <raw_dir> <out_dir> [column ...]
```
`<raw_dir>` holds the text files produced by the derivation scripts, at the relative paths listed in
`make_columns_524k.py` (`SOURCES`). The script keeps the first whitespace- or comma-separated token of each line.
The shipped prefixes were checked against the study: each reproduces its flip profile in
`data/sec2_study/A/csv/flip_profiles.csv` exactly (maximum difference below 1e-16).

## Table 2 statistics
`compute_column_stats.py <datasets_root> <out.csv>` computes the exact row and distinct counts behind Table 2
(integer columns over the rows of the Sec. 7 size runs, floats over their 524,288-row files). Its output for
the paper is `data/table2_column_stats/column_stats.csv`; it was run read-only over the full-length files on the
benchmark host (`run.log` alongside). The five float counts were cross-checked on a second copy of the files.

## Missing
- No original script was found, on the benchmark host or locally, for: the ALP archive extraction, the
  parquet-to-text exports (TPC-H, IPv4, iNaturalist), the Instagram extraction, the Food-prices cut and the
  uniform float control. The reconstructions above replace them; all but the ALP one are verified byte for
  byte against the files used in the paper.
- The Public BI float extractions (F3 Gov/10 and F9 NYC/29 come from the ALP archive; F4 and F10 are copied
  verbatim from the Medicare1 extract of `generate_publicbi_ints.py`) need no further script.
